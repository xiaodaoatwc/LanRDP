# Privacy and example data / 隐私与示例数据

## 中文

提交代码、文档、测试、截图、日志或 Release notes 前，请过滤真实环境信息：

- 真实电脑名、客户名、公司名、域名；
- 真实 IP、端口映射、VPN 地址；
- 真实用户名、路径、邮箱；
- 真实日志中的主机名、证书、会话信息。

请使用通用示例：

```text
主机：192.0.2.10          # RFC 5737 文档地址
域名：example.com         # RFC 2606 保留域名
电脑名：Example-PC
用户名：testuser
路径：/Users/example
```

`KNOWN_ISSUES.md`、`CHANGELOG.md`、README、GitHub Release notes 和测试代码同样适用。

## English

Before committing code, docs, tests, screenshots, logs, or release notes, remove real environment data:

- Real PC, customer, company, or domain names
- Real IP addresses, port mappings, or VPN endpoints
- Real usernames, paths, or email addresses
- Hostnames, certificates, or session details in logs

Use generic examples:

```text
Host: 192.0.2.10          # RFC 5737 documentation address
Domain: example.com       # RFC 2606 reserved domain
PC name: Example-PC
Username: testuser
Path: /Users/example
```

This also applies to `KNOWN_ISSUES.md`, `CHANGELOG.md`, README, GitHub release notes, and test code.
